# Hassan Gebril — Portfolio

A recruiter-focused portfolio for AI, machine learning, data science, and data engineering opportunities.

## Live site

https://hassang04.github.io/portfolio/

## Highlights

- Responsive single-page experience with accessible navigation and reduced-motion support.
- Evidence-led case studies featuring real evaluation metrics.
- Professional experience, education, technical capabilities, and current learning goals.
- Structured metadata and Open Graph sharing support.
- Built with semantic HTML, modern CSS, and lightweight vanilla JavaScript.

## Local preview

Open `index.html` directly or serve the repository with any static web server.

## Deployment

GitHub Actions publishes the `main` branch to GitHub Pages.
