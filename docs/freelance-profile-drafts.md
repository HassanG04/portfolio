## Khamsat — العربية

### نبذة الملف الشخصي

أنا حسن جبريل، أعمل على تطبيقات Python وتجهيز البيانات والتعلم الآلي. أهتم بتحويل المهمة إلى مخرجات محددة يمكن مراجعتها وتشغيلها، مع توثيق واضح وشرح للنتائج. أقدم خدمات محددة لتنظيف البيانات، وبناء نماذج تنبؤية أولية، وإتاحة النماذج المدربة عبر واجهات API، وفق نطاق نتفق عليه داخل المنصة.

### الخدمة الأولى: تنظيف بيانات CSV والتحقق من جودتها باستخدام Python

هل تواجه قيمًا مفقودة أو سجلات مكررة أو تنسيقات غير موحدة؟ سأراجع ملفك باستخدام pandas، وأطبق قواعد تنظيف واضحة دون حذف السجلات أو تعويض القيم بصمت.

**نطاق مقترح للمراجعة قبل النشر:** ملف CSV واحد حتى 10,000 صف و20 عمودًا، مع خمس قواعد تنظيف متفق عليها ومراجعة واحدة ضمن النطاق. يجب اعتماد هذه الحدود والسعر والمدة قبل تفعيل الخدمة.

**ما ستستلمه:** ملف CSV منظف، وملف بالسجلات التي تحتاج مراجعة مع سبب الرفض، وملخص للتغييرات، وسكربت Python مع تعليمات تشغيله. لا تشمل الخدمة تدريب نموذج، أو تصميم لوحة معلومات، أو جمع بيانات من المواقع.

**المطلوب منك:** عينة من الملف، ومعنى الأعمدة، وقواعد العمل، وتأكيد حقك في مشاركة البيانات. أزل المعلومات الشخصية والأسرار قبل إرسال العينة.

### الخدمة الثانية: بناء نموذج تعلم آلي أولي لبيانات جدولية

سأبني نموذجًا أوليًا للتصنيف أو الانحدار من بياناتك المعلّمة، مع خط أساس للمقارنة وتقسيم منفصل للتدريب والاختبار. يشمل التسليم كود تجهيز البيانات والتدريب، وتقرير المقاييس، وتعليمات إعادة التجربة. لا أضمن نسبة دقة مسبقة؛ النتائج تعتمد على البيانات والمهمة. نشر API أو تطبيق ويب ليس ضمن هذه الخدمة.

قبل النشر: حدّد حجم البيانات، وعدد النماذج، والمراجعات، والسعر، والمدة. اطلب من المشتري تحديد العمود المستهدف وكيفية استخدام التنبؤات.

### الخدمة الثالثة: إتاحة نموذج مدرّب عبر FastAPI

سأربط نموذجًا مدرّبًا ومتوافقًا بواجهة تنبؤ تتحقق من المدخلات وتعيد النتيجة بصيغة JSON. يشمل التسليم التطبيق، ومثال طلب، واختبارات للمدخلات، وتعليمات التشغيل. لا تشمل الخدمة تدريب النموذج أو استضافة مدفوعة أو نشرًا سحابيًا.

قبل النشر: اتفق على صيغة النموذج، ومخطط المدخلات، وعدد المسارات، والبيئة المطلوبة، والسعر والمدة. اطلب من المشتري ملف النموذج ومكتباته وإصداراتها ومثالًا لمدخل صحيح؛ لا تطلب كلمات مرور أو مفاتيح سرية.
